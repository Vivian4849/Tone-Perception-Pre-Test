How to set it up

Three things to fill in

  • 1 Audio — either paste file paths (audio/q1.mp3) into assets/config.js, or load the files at runtime from the “Setup (teacher only)” panel on each test page.
  • 2 Answer key — the tone number for every item, in assets/config.js or in the same setup panel.
  • 3 Collection — paste your Google Apps Script Web App URL into ENDPOINT at the top of assets/app.js. Until then, every submission is saved as a CSV.
